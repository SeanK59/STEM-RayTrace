Display

What this page is. The ray trace's column — the same element table (column.js), the same thin lenses, the same lens settings — with electron-wave mechanics added and nothing else. Open it from the ray page's wave-optics view link and it starts from that page's lenses; leave both open and it follows every change live. The ray page stays the control panel: convergence angle, probe focus and every lens are set there.

The probe is the ideal converging wave the ray model describes — a sharp cone of half-angle α (the VOA's edge, far in the Fraunhofer regime) — with the aberration phase χ(θ,φ) = (2π/λ) Σ θn+1/(n+1) [Cnm,a cos mφ + Cnm,b sin mφ] up to third order (C10 … C34). The ray page's probe defocus, how far the specimen sits past the probe crossover, is added to C10, so moving the specimen there defocuses the probe here. Under parallel illumination the incident wave is a plane wave, whose illuminated radius is always far larger than this window.

The downstream plane is reached with the column's own paraxial transfer matrix [[A,B],[C,D]] from the specimen, through the Collins integral — the wave-optical counterpart of the ABCD matrix the ray page draws with. At a diffraction plane (A = 0) it is a scaled Fourier transform: CBED discs of radius L α at spacing L λ/d, L = |B|, exactly where the ray page puts the beam edge and its Bragg discs (the dashed overlay). At an image plane (B = 0) it is a magnified copy of the exit wave; anywhere between, a shadow image or Ronchigram. Near diffraction planes it is evaluated as chirp · FFT, near image planes as an exact angular-spectrum propagation over B/A followed by a magnification A; the switch-over is where each stops being sampled well, so between them they cover every plane.

The window is chosen per render: the pixel must resolve every angle present (the probe cone plus two Bragg orders, times the oversample factor), so the window is N pixels of that. A strongly defocused probe can outgrow it — the caption says so rather than drawing aliased nonsense; use C10 for fine defocus, or raise the grid. The EELS limiting aperture is ignored: every electron reaches every plane.

Specimens are thin phase objects: a square lattice t = exp(iσ[cos(2πx/d) + cos(2πy/d)]), whose orders sit at ±λ/d (with d = 3.1355 Å, Si {111}, at 200 kV that is 8.00 mrad, and 0.451 mm between the ±1 discs at L = 28.2 mm); amorphous carbon as a Gaussian-correlated random phase screen; or vacuum. No multislice, no absorption, no inelastic scattering, no partial coherence, no chromatic spread. Append ?selftest to check the propagator against closed-form results.
